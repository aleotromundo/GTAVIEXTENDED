# Mapa de navegación de Nowarfy · YouToo

La barra lateral de Nowarfy reemplaza la organización genérica del portal por una estructura audiovisual. Conserva las rutas nativas de MediaCMS para la biblioteca propia y agrega acciones locales directas para la cola, el reproductor y la privacidad del dispositivo.

| Grupo lateral | Acceso | Destino o acción |
|---|---|---|
| Descubrir | Inicio | Portada Nowarfy con la biblioteca disponible. |
| Descubrir | Destacados | Ruta nativa de contenido destacado. |
| Descubrir | Para vos | Ruta nativa de recomendaciones disponibles. |
| Descubrir | Novedades | Ruta nativa de incorporaciones recientes. |
| Descubrir | Categorías y Etiquetas | Archivos taxonómicos de MediaCMS. |
| Tu biblioteca | Mi biblioteca | Archivos del usuario actual. |
| Tu biblioteca | Mis listas | Listas creadas o guardadas por el usuario. |
| Tu biblioteca | Favoritos e Historial | Rutas nativas de actividad y contenido marcado. |
| Tu experiencia | Tu cola | Expande el reproductor flotante y abre la cola persistente local. |
| Tu experiencia | Reproductor | Muestra el control flotante sin cambiar de página. |
| Tu experiencia | Tus datos | Abre el panel local de privacidad, preferencias, búsquedas y actividad. |
| Crear y gestionar | Agregar a la biblioteca | Flujo nativo de subida de archivos propios. |
| Crear y gestionar | Administración | Rutas de gestión visibles solo según los permisos del usuario. |

> La cola, el reproductor y el perfil local viven en el dispositivo por defecto. La sincronización con Supabase continúa desactivada hasta que exista una cuenta y un consentimiento explícito.
